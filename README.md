# Student Management System

## Project Overview
Student Management System is a simple menu-driven Java console application developed to manage student records efficiently.

## Features
- Add Student
- View All Students
- Search Student
- Update Student Details
- Delete Student
- Save and Load Student Records using File Handling

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- Serialization

## Project Structure
```text
StudentManagementSystem-Project/
│
├── StudentManagementSystem/
│   └── Main.java
│
└── README.md
```

## How to Run

Compile:
```bash
javac -d . StudentManagementSystem/Main.java
```

Run:
```bash
java StudentManagementSystem.Main
```
